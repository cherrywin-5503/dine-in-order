# 堂食扫码点单系统（快餐店）

软件工程课程项目。顾客扫码点单、模拟付款、凭取餐号取餐；店员接单出餐；店长管理菜单和账号。
需求和设计见课程提交的《需求分析文档》《软件设计文档》，编号（FR-xx、NFR-xx、EX-xx）和文档一致。

作者：尚止忧　I202420081

## 技术栈

- 前端：原生 HTML + CSS + JavaScript（手机优先，电脑也能用），没有用框架
- 后端：Node.js（只用自带的 http 模块），没有第三方依赖
- 数据库：SQLite（Node 自带的 `node:sqlite`）
- 支付：MockPay 模拟微信支付（真实微信支付需要商户号和备案域名，见设计文档 A1）
- 测试：Node 自带的 `node:test`

## 运行（Mac）

1. 安装 Node.js（版本 22.13 或更高）。去 https://nodejs.org 下载 LTS 安装包，装完在终端输入 `node -v` 能看到版本号就行。
2. 在终端进入项目文件夹，输入：

   ```
   npm start
   ```

   不需要 `npm install`，没有依赖要装。
3. 看到“堂食扫码点单系统已启动”就成功了。浏览器打开 http://localhost:3000/

## 页面入口

- 顾客端：`/`
- 店员端：`/staff.html`　账号 `staff1` 密码 `staff123`
- 店长端：`/manager.html`　账号 `manager` 密码 `manager123`
- 入口导航：`/entry.html`（顾客、店员、店长三个二维码，手机扫码打开）
- 点餐码：`/qr.html`（打开后用手机扫，就是店内统一点餐码）

## 用手机访问

1. 手机和电脑连同一个 WiFi（学校 WiFi 如果不行，就让电脑连手机热点）。
2. 启动后终端会打印“手机访问”的地址，例如 `http://192.168.1.23:3000/`，在手机浏览器里输入，或者打开 `/qr.html` 用手机扫。
3. 想像 App 一样用：手机浏览器里选“添加到主屏幕”，桌面会出现图标，打开时没有地址栏。
4. 店员端建议在手机或平板上打开，点一下“开始接单”才会有提示音。

## 5 分钟演示流程

1. 电脑打开店员端，登录，点“开始接单”。手机扫点餐码进顾客端。
2. 顾客：点“牛肉米粉”，选大碗和辣度，再加一个茶叶蛋，填备注，提交，点“确认支付”。
3. 手机上出现取餐号和“等待中”；电脑店员端响铃并出现订单。
4. 店员点“开始制作”→“已完成（叫号）”，手机上自动变成“已完成，请取餐”。
5. 再用另一台手机或浏览器下一单，看“前面还有 N 个订单”。
6. 店员在“售罄管理”里打开一个菜的开关，顾客菜单 4 秒内变灰。
7. 店长端：改价、新增菜品、查订单。
8. 异常演示（店长端“演示”页）：模拟退款失败、快进 16 分钟让未支付订单自动关闭。

## 目录结构

- `server.js`：启动入口
- `src/app.js`：接口层（路由、登录和角色校验、统一返回格式）
- `src/auth.js`：登录和 token
- `src/menu.js`：分类、菜品、规格、价格计算
- `src/orders.js`：订单核心（状态机、取餐号、排队数、支付确认、退款、定时任务）
- `src/mockpay.js`：模拟微信支付
- `src/db.js`：建表和演示数据
- `src/qr.js`：二维码生成
- `public/`：三个前端页面
- `test/api.test.js`：自动化测试
- `docs/`：讲解单、提交计划、测试报告模板、与设计文档的差异

## 常用命令

- 清空数据重新开始：`npm run reset`
- 换端口：`PORT=8080 npm start`
- 关闭演示开关：`DEV_TOOLS=0 npm start`

## 电脑软件版（可选）

店员端和店长端可以做成 Mac 上的独立窗口软件（Electron）：

```
cd desktop
npm install
npm run staff      # 店员端窗口
npm run manager    # 店长端窗口
```

会自动启动后端服务。需要联网下载 Electron（约 100 MB），第一次比较慢。这一部分我没有在你的环境里测试过，如果装不上，直接用浏览器打开店员端也一样能演示。
